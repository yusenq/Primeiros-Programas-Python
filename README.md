# Primeiros-Programas-Python
Programas básicos desenvolvidos durante meus estudos de Python. - Basic programs developed during my Python studies.


# Porque Criei Este Repositório?
Este repositório foi criado para marcar minha evolução.

# Programas
- python_0_print -> Neste programa, aprendi a exibir minha primeira mensagem na tela.

- python_1_var.py -> Já neste programa, aprendi a declarar e definir valor para a minha primeira variável.

- python_2_soma.py -> Neste programa, vi sobre o uso dos principais operadores matemáticos em Python.

- python_3_operacoes.py -> Ainda trabalhando com operadores matemáticos, vi um pouco mais a fundo o uso deles.

- python_4_dobro.py -> Neste programa, trabalhei com manipulação de dados matemáticos (sem ser para contas ou operações de resultado direto).

- python_5_antecessor.py -> Assim como no ultimo programa, utilizei operadores matemáticos de forma indireta, me resultando um valor que respondesse o enunciado, e não a conta em si.

- python_6_media.py -> Aqui, pela primeira vez, vi loop usando FOR e condicionando o mesmo com os comandos IN e RANGE.

- python_7_conversao.py -> Neste programa, estudei pela primeira vez o uso dos comandos condicionais IF e ELSE.

- sistema_aprovacao.py -> Neste código, além de fortalecer o uso do IF e ELSE, estudei a utilização do ELIF. E após isso, pesquise sobre boas práticas de nomenclatura.

- sistemas_de_senhas.py -> Aqui estudei um pouco mais sobre a utilização de WHILE junto de IF e ELSE, porém, ainda com dificuldade em formatação e arquitetura de código.

- somador.py -> Aqui, pela primeira vez, utilizei listas e o comando SUM (Que literalmente faz a soma de todos os números presentes em uma lista).

- tabuada.py -> Neste programa, utilizei mais do loop com FOR IN RANGE. Além disso, trabalhei com operadores aplicados somente a variáveis.

- calculadora.py -> Uma calculadora simples, onde estudei e testei o máximo possível sobre condicionais e lógica matemática.

- calculo_imc.py -> Um exercício complementar que usei para aprender um pouco mais à fundo condições com IF, ELIF e ELSE.

- contador.py -> Outro exercício, agora para aprender mais sobre loops usando FOR, IN e RANGE.

- determinante_idade.py -> Neste exercício, estudei mais profundamente a utilidade de IF, ELIF, ELSE.

- jogo_de_adivinhação.py -> Neste programa, entendi um pouco mais a fundo o uso do WHILE e a aplicação de condicionais dentro de um loop.

- maior_e_menor.py -> Neste arquivo, exercitei mais um pouco meu manejo com listas.

- carrinho_de_compras.py -> Aqui apliquei tudo que aprendi até agora (09/09/2026), e aprendi sobre a utilização de DEF, que junta blocos de comandos em containers, para que eu consiga reutilizar esses blocos inteiros em outro momento, como uma única função.

- media_lista.py -> Feito para descobrir como checar listas com for. Ainda preciso de muita prática com isso, mas consegui reconhecer meus erros por enquanto.

- cadastro_de_pessoas.py -> Feito para testar o uso mais complexo de condicionais e lógica de programação.

- sistema_de_estoque.py -> Ainda não está pronto e é apenas a primeira versão, pretendo termina-lo, e após isso, pretendo melhorar e otimizar esse sistema com DEF.
